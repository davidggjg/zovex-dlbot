# zovex-dlbot

בוט טלגרם להורדת וידאו ואודיו מיוטיוב, טיקטוק, אינסטגרם ועוד מאות אתרים —
עם בחירת איכות וכתוביות דרך כפתורים, ועד **2GB** לקובץ.

---

## למה 2GB ולא 50MB

לבוט רגיל שמדבר מול `api.telegram.org` יש תקרה של 50MB להעלאה ו-20MB להורדה.
הפתרון הוא **Telegram Bot API Local Server** — גרסה עצמאית של ה-API שרצה על
אותו VPS. `install.sh` בונה אותה בשבילך.

| | ענן טלגרם | שרת מקומי |
|---|---|---|
| העלאה מהבוט | 50MB | **2000MB** |
| הורדה לבוט | 20MB | ללא הגבלה |
| שליחת קובץ | העלאה ב-HTTP | העברה לפי נתיב בדיסק (מיידי) |

נדרשים `api_id` ו-`api_hash` מ-https://my.telegram.org → *API development tools*.

---

## התקנה

על ה-VPS (Ubuntu/Debian, גם ARM):

```bash
curl -fsSL https://raw.githubusercontent.com/davidggjg/zovex-dlbot/main/install.sh -o install.sh
sudo bash install.sh
```

הסקריפט עושה הכל: חבילות מערכת, ffmpeg, משתמש מערכת, swap (אם צריך),
בניית השרת המקומי, סביבת Python, קובץ `.env`, ו-systemd services.
הוא ישאל אותך רק ארבעה דברים: `api_id`, `api_hash`, `BOT_TOKEN`, `ADMIN_IDS`.

> אם הבוט כבר דיבר פעם מול הענן, צריך פעם אחת
> `curl -s 'https://api.telegram.org/bot<TOKEN>/logOut'`
> לפני שהוא יוכל לעבוד מול השרת המקומי.

## מה הבוט עושה

שולחים קישור → הבוט מנתח ומציג:

- **🎬 איכויות וידאו** — רק מה שקיים בפועל, עם הערכת גודל ליד כל אחת (4K/1440/1080/720/480/360)
- **🎵 אודיו** — MP3 (עם תמונת שער ומטא-דאטה) או M4A
- **💬 כתוביות** — אם יש:
  - **מקוריות** (מה שהיוצר העלה) או **אוטומטיות** (תמלול מכונה)
  - רשימת שפות עם דפדוף, עברית ואנגלית ראשונות
  - **כל השפות** בקובץ ZIP אחד
  - ארבע דרכים לקבל: `SRT` · `VTT` · **משולב** ב-MP4 (מהיר, אפשר לכבות בנגן) · **צרוב** בתמונה (קידוד מחדש)
- **🛑 ביטול** של הורדה רצה
- שורת התקדמות חיה: אחוזים, גודל, מהירות, זמן שנותר

## מגבלות ובקרה

הבוט פתוח לכולם, עם בלמים שמונעים הצפה של השרת. הכל ב-`/opt/dlbot/.env`:

| הגדרה | ברירת מחדל | מה זה |
|---|---|---|
| `MAX_FILESIZE_MB` | 1950 | תקרה לקובץ בודד |
| `DAILY_QUOTA_MB` | 4000 | נפח יומי למשתמש |
| `DAILY_JOBS` | 25 | הורדות ביום למשתמש |
| `GLOBAL_CONCURRENCY` | 2 | הורדות במקביל בכל השרת |
| `USER_CONCURRENCY` | 1 | הורדות במקביל למשתמש |
| `COOLDOWN_SECONDS` | 3 | מרווח בין בקשות |
| `MAX_DURATION_MINUTES` | 240 | אורך וידאו מקסימלי |

בקשות מעבר ל-`GLOBAL_CONCURRENCY` נכנסות לתור ומקבלות מקום בתור בהודעה.

### פקודות אדמין

| פקודה | מה זה עושה |
|---|---|
| `/stats` | משתמשים, הורדות היום, כשלונות, מצב התור |
| `/cookies` | מעלה קובץ `cookies.txt` לאתרים שדורשים התחברות |
| `/block <id>` / `/unblock <id>` | חסימת משתמש |

**cookies**: אינסטגרם, ולפעמים יוטיוב, דורשים התחברות. מייצרים `cookies.txt`
בפורמט Netscape (תוסף דפדפן כמו *Get cookies.txt LOCALLY*), שולחים לבוט אחרי
`/cookies`, ושם הקובץ קובע לאיזה אתר הוא משויך: `instagram.txt`, `tiktok.txt`,
`youtube.txt`, `facebook.txt`, `twitter.txt`, `reddit.txt`, או `cookies.txt` כגנרי.
הקובץ נשמר ב-`/var/lib/dlbot/cookies` עם הרשאות 600.

## תחזוקה אוטומטית

| timer | מה |
|---|---|
| `dlbot-update.timer` | מעדכן `yt-dlp` כל יום ב-04:17 ומפעיל מחדש — חובה, האתרים משתנים כל הזמן |
| `dlbot-cleanup.timer` | מוחק כל שעה שאריות הורדות מעל 3 שעות, כדי שהדיסק לא יתמלא |

```

app/ytdl.py       כל מה שנוגע ל-yt-dlp ו-ffmpeg

app/jobs.py       תור עבודות, שורת התקדמות, שליחת הקבצים
app/handlers.py   פקודות ולחיצות על כפתורים
app/main.py       הרכבה והפעלה
```

## פתרון תקלות

| תסמין | מה לבדוק |
|---|---|
| `Sign in to confirm you're not a bot` | צריך cookies ליוטיוב (`/cookies`) |
| אינסטגרם נכשל | cookies לאינסטגרם |
| `Unauthorized` אחרי מעבר לשרת מקומי | לא הורץ `logOut` על הענן |
| קובץ נשלח כמסמך ולא כוידאו | טלגרם דחה את הקודק; הבוט נופל חזרה למסמך בכוונה |
| צריבת כתוביות נתקעת | 2 ליבות זה איטי לקידוד — עדיף "משולב" במקום "צרוב" |
| הדיסק מתמלא | `systemctl start dlbot-cleanup` |
